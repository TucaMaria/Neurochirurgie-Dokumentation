# T-LIF – Eingabemaske
Nur in einer für Falldaten freigegebenen Umgebung ausfüllen.

- Diagnose / Segment / Beschwerdeseite:
- Voroperationen / relevante Bildgebung / Indikationsabwägung:
- Datum / Operateur / Assistenz:
- Anästhesie / Lagerung:
- Offener oder minimalinvasiver Zugang / Revision:
- Dekompressionsseite und Ausmaß:
- Interkorporelle Zugangsseite:
- Tatsächliche Operationsschritte in Reihenfolge:
- Intraoperative Befunde / Narbenverhältnisse / Nervenwurzel / Dura:
- Schrauben- und Stabsystem, Segmente, Maße:
- Cage-System, Maße und Anzahl:
- Fusionsmaterial / Herkunft:
- Navigation / Durchleuchtung / weitere Bildkontrollen:
- Blutverlust / Besonderheiten / Komplikationen und Maßnahmen:
- Drainage / Wundverschluss:
- Postoperative Anordnungen:

Nicht alle Punkte gleichzeitig erfragen, wenn bereits ein Teil aus Falldaten bekannt ist. Fehlende wesentliche Details nacheinander klären.

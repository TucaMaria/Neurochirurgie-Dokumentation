# Eingang vorhandener Vorlagen
Hier vorhandene Prompts und anonymisierte Muster zur Konsolidierung ablegen.

Für jede Datei dokumentieren: Herkunft, Dokumenttyp, Pathologie/Eingriff, Variante, Stand und Freigabestatus. Identifizierende Angaben und patientenbezogene Metadaten vor einer Verarbeitung außerhalb der freigegebenen Krankenhausumgebung entfernen.

Originalformulierungen nachvollziehbar erhalten; Dubletten, Konflikte und veraltete Aussagen kennzeichnen. Erst nach Prüfung in Referenzen oder Textbausteine übernehmen.
